# 店内打卡区方案

## 三原则

1. **整体性**——背景干净，不能杂乱
2. **互动性**——让人愿意走进去、站进去，不只是路过拍一张
3. **品牌记忆点**——照片里必须有"小灼"或"三亚铁板烧"信息

## 三个分级方案

### 方案一：火焰霓虹墙（长期品牌感）

- 深色底 + 暖红 / 橙色 LED 霓虹
- 主字：CHILL'O 小灼 / FIRE & BREW
- 配火焰造型霓虹灯，与火焰秀呼应
- 预算：3000–5000 元
- 优点：暖红光拍人脸好看，长期可用

### 方案二：精酿打卡角（先做，见效最快）

- 霓虹灯牌"9.9 精酿自由" + 干冰烟雾效果
- 与精酿活动绑定
- 预算：500–1000 元
- 优点：成本最低，拍出来即免费广告

### 方案三：三亚海岛记忆点墙

- 椰子树 + 海浪 + 和牛元素
- 霓虹字："在三亚，吃一场会喷火的铁板烧"
- 互动设计："三亚"二字缺笔画，需两人站上去补全——情侣 / 闺蜜必拍
- 预算：2000–4000 元

## 不花钱的加分项

- 铁板前最佳拍摄位，地面贴"这里拍火焰最出片"
- 师傅上火焰菜时提醒一句"这个角度拍最好看"
- 等位区小黑板，让客人写"我在小灼"拍照

## 落地顺序建议

先做方案二（成本最低、绑活动见效快）→ 再上方案一（长期品牌感）→ 方案三视空间而定。
