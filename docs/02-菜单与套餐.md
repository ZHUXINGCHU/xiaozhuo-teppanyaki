# 菜单与套餐

> 依据历史资料整理，价格为当时的活动价，实际以门店/团购页为准。

## 菜品结构

### 前菜 / 汤 / 沙拉

- 鹅肝鱼籽蒸蛋
- 法式鹅肝（含百香果、树莓等酱汁方向）
- 南瓜奶油汤 / 西式浓汤
- 什锦沙拉
- 寿司：芒果琉璃卷、芒香琉璃卷

### 主菜 · 牛排

- 战斧牛排（牛肋脊部位，肉质紧实、油花饱满）
- 山葵肉眼牛排
- 澳洲谷饲菲力牛排
- 新西兰羊肋排
- 新西兰牛肋条（切骰子块，蒜片黑胡椒爆炒，淋烧肉汁）

### 主菜 · 海鲜

- 柠汁金枪鱼 / 柠汁金鲳鱼
- 香煎龙利鱼（配海南糟粕醋 + 南瓜汁）
- 南美白对虾（蒜蓉 / 芝士双口味）
- 开背蒜蓉虾

### 主食 / 甜品

- 牛肉炒饭（"会跳舞的炒饭"）
- 火焰冰激凌（压轴表演：香蕉块 + 冰淇淋球 + 高度白酒点燃）
- 甜品「万物生长」

## 套餐设计原则

- 用**一道硬菜**（战斧 / 菲力 / 羊排）扛价值感
- 用**一道海南元素**（糟粕醋龙利鱼）做记忆点
- 用**表演菜**（火焰冰激凌）收尾，制造拍摄点
- 用汤、沙拉、炒饭、寿司**撑满桌面**，让客人觉得"一大桌"
