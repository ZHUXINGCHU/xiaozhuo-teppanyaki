# 品牌与门店

## 基本信息

| 项目 | 内容 |
|---|---|
| 品牌名 | Chill'O 小灼铁板烧 |
| 门店 | 三亚大悦城 6 楼 |
| 业态 | 中高端板前铁板烧 |
| 人均 | 百元档（双人套餐 188～258） |
| 主营 | 和牛 / 牛排、海鲜、鹅肝、寿司、铁板现做 |

## 品牌调性

一句话：**烟火气 + 洋气**。

- 明档板前：食材整齐陈列，顾客坐在铁板台前，厨师在台后现场烹制
- 现场感：火焰表演、滋滋作响、铲刀翻飞
- 场景：情侣约会、朋友聚会、家庭带娃、游客打卡

## 客群

1. 三亚本地年轻客群（约会、聚餐）
2. 外地游客（认"海南特色""现场表演"）
3. 俄籍及亲子游客（亚龙湾方向重点客群）

## 品牌延展

- 计划升级方向：**小灼肉铺**（延续明亮精品、洋气风格）
- 亚龙湾分店命名含 **Chillo**，面向俄籍与亲子游客

## 关键记忆点

- 板前现做，不是后厨出餐
- 火焰秀（火焰冰激凌、火焰浇汁）
- 海南本土元素（糟粕醋、百香果、椰子、清补凉）
