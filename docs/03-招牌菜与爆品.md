# 招牌菜与爆品

## 一、爆品判断标准

记忆点 + 仪式感 + 传播性 + 差异化壁垒 + 成本可控。

## 二、主推方向（推荐）

### 1. 糟粕醋铁板和牛 —— 主招牌

- 逻辑：糟粕醋是海南"身份证"，游客天然认；高端铁板烧 + 糟粕醋几乎无竞品
- 升级路径：由现有的"糟粕醋龙利鱼"升级到和牛
- 出餐设计：和牛煎至焦香 → 现场浇糟粕醋汁 → 火焰冲起

### 2. 百香果鹅肝 —— 副招牌 / 前菜

- 逻辑：海南百香果 × 法式鹅肝，酸甜解腻，记忆点强
- 优势：鹅肝已有，换酱汁即新菜，改动成本低

### 3. 芝士火焰小青龙 —— 表演菜

- 逻辑：芝士拉丝 + 火焰点燃，双爆点，抖音画面天然成片

## 三、备选爆品

| 菜品 | 特点 | 适合场景 |
|---|---|---|
| 火焰大战斧 | 传播强，但同质化 | 节点活动 |
| 蓝鳍金枪鱼开鱼宴 | 高端、复购门槛高 | 事件营销 |
| 紫苏和牛卷（含爆珠） | 薄切和牛裹紫苏，内包飞鱼籽爆珠 | 差异化单品 |
| 洋葱火山 | 日式经典表演，成本极低 | 氛围菜 |
| 龙虾膏酱小青龙 | 比芝士版更高级 | 升级款 |
| 糟粕醋火焰虾 | 与主推方向组合 | 组合套餐 |

## 四、噱头菜清单（低成本优先）

### 火焰表演

- 蓝焰火焰三文鱼（淋清酒点火，蓝焰包裹鱼身）
- 白兰地火焰老虎斑（整鱼点火）
- 火焰冰激凌（已有，保留为压轴）

### 干冰冒烟

- **冒烟精酿**（干冰 + 精酿，成本极低，拍照爆点）
- 干冰冒烟海胆 / 刺身

### 互动整活

- 洋葱火车（洋葱圈串成火车在铁板推行，最后点火）
- 铁盖蒸箱小青龙（盖铁盖蒸汽循环，掀开蒸汽腾起）

### 高端视觉

- 22K 可食用金箔和牛（金箔成本极低，高端感强）
- 黑松露现场刨片

> 原则：噱头是锦上添花，不喧宾夺主。真招牌是「糟粕醋和牛 + 百香果鹅肝」，噱头负责让客人拍照发抖音。

## 五、上菜节奏建议

一次上 2–3 道即可，最优组合：

1. 糟粕醋和牛（主菜招牌）
2. 百香果鹅肝（前菜 / 副招牌）
3. 芝士火焰小青龙 或 洋葱火山（表演菜）

= 有海南记忆点 + 有视觉表演 + 有高端食材。
